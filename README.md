## ✨ Features

✅ Real-time monitoring of concrete curing process  
✅ Clean, responsive UI with interactive visualizations  
✅ 📊 Sensor-based graph plotting (temperature, humidity, etc.)  
✅ Export sensor reports (Excel)  
✅ Login & Signup authentication system 🔒  
✅ Modular, scalable Flask backend with Firebase/Chart.js support
